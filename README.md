# 海外 AI 短剧视觉资产提示词工作台

本项目把剧本、资产表、参考图和成图反馈转为可直接复制的 **场景、角色与群演、道具、封面** 图片提示词。四个模块共享一次剧本事实提取，再按各自规则生产；默认**只写提示词**，用户明确要求时才生成图片。

## 零上下文启动

1. 阅读 [AGENTS.md](AGENTS.md) 和 [共享基础](工作台/共享基础.md)。
2. 判断本轮是读剧本、核验资产表、写提示词、复盘成图，还是实际出图；只进入下表的当前模块。
3. 读取当前剧目的完整剧本、`剧目状态.md`、用户资产表与本轮参考材料；其他剧目只作明确要求下的历史查证。
4. 建立并复用**一份共享事实账**；模块资产表从共同事实账产生，仍由用户决定制作范围。
5. 默认采用写实仿真人路线。用户明确指定动画方向或当前剧目已有确认的动画风格时，才读取 [可选风格分支](风格项目/明亮写实卡通/README.md) 的相关章节。

## 当前任务路由

| 用户当前任务 | 读取入口 | 下一步 |
| --- | --- | --- |
| 场景列表、场景提示词、状态帧、场景成图反馈 | [场景模块](工作台/模块/场景.md) | 完整剧本 → 证据分类 → 精简资产表或提示词；Snn 按基础图状态判断 |
| 人物脸、服装板、配角与群演 | [角色与群演模块](工作台/模块/角色与群演.md) | 核验身份与造型需求，按人物参考条件交付概念或提示词 |
| 剧情道具、证据物、物件多视图 | [道具模块](工作台/模块/道具.md) | 先判断制作与复用，再写道具板提示词 |
| 短剧主封、封面文字与人物关系 | [封面模块](工作台/模块/封面.md) | 锁定英文剧名及角色身份，先给不同视觉概念 |

`项目记忆.md` 保存跨剧用户偏好及反馈来源，按当前模块相关标题读取；模块 reference 是该模块详细规范的维护来源。原始 V4.1 记忆包与 [整理前文件](工作台/历史/) 只作历史追溯。

## 新剧目

复制 [新剧目模板](模板/新剧目/) 到 `剧目/剧名/`；保留用户原始输入，填写 [共享事实账模板](模板/新剧目/01_共享事实账模板.md) 与 `剧目状态.md`。已有资产表先核验并保留来源条目；没有时建立最小但完整的清单。团队资产表保持简单，剧本证据、取舍和版本状态记录在内部文件。

可复制模板中的链接只指向同批复制的剧目文件；不依赖模板原有目录层级去访问工作台规则。AI 先从工作台入口读取规范，再填写剧目文件；若用户将剧目放到其他目录，仍保留它们自己的有效内部链接。

每轮区分 **提示词完成、图片生成、用户认可**。实际成图反馈先观察图片，定点修订，更新当前剧状态；只有跨剧稳定的规则再更新项目记忆或模块规范。旧版保留但注明被哪一版取代，不无故移动已被引用的历史交付路径。

| 模块 | 普通聊天上传 | 可读本地文件的工具 | 入门说明 |
| --- | --- | --- | --- |
| 场景 | [单份 Markdown 指南](导出/场景图提示词工作台_独立指南.md) | [本地包](导出/场景图提示词工作台_本地包/README.md)及同名 ZIP | [小白使用说明](导出/场景图提示词包_小白使用说明.md) |
| 封面 | [单份 Markdown 指南](导出/封面图提示词工作台_独立指南.md) | [本地包](导出/封面图提示词工作台_本地包/README.md)及同名 ZIP | [小白使用说明](导出/封面图提示词包_小白使用说明.md) |

原项目的共享基础、各模块 reference、模板与按需启用的风格规范是**维护来源**；导出物是发布快照。修改源规则后按 [导出同步说明](导出/README.md) 重新校对并打包，不在多个副本中独立维护规范。
