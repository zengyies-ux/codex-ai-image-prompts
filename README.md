# 海外 AI 短剧视觉资产提示词工作台

核心是图片的整体设计与可复制提示词。你可以从一段需求、一张参考图、现有提示词的局部修改，或指定剧目的资产任务开始。剧本解读服务当前设计，**默认只写提示词**，明确要求才生成图片。

## 如何开始

AI 先读 [AGENTS.md](AGENTS.md) 与 [共享基础](工作台/共享基础.md)，再进入当前模块；不用遍历历史剧目或全部规则。

| 当前输入 | 路径与交付 |
| --- | --- |
| 文字需求、单张设计、局部修改 | 明确模块、用途与必要条件，直接构思和写提示词。低影响选择标注假设；不强制剧本、目录或资产表 |
| 用户参考图 | 实际打开图，确定还原／转译／改版及参考职责；用少量具体证据说明保留与调整，再写提示词 |
| 指定剧目、要求剧情一致、完整剧本资产任务 | 从 [剧目资料入口](剧目/README.md) 找到指定作品；核实版本、状态、有关原文与来源。首次完整剧本任务通读并建立解读；整剧范围由用户确认后分批制作 |

混合输入可一起使用。已有充分资料、已选方案或明确的修复要求时直接交付，不重复概念审批；只问会实质改变当前结果的缺口。

## 四个正式模块

| 任务 | 入口 | 默认交付规格 |
| --- | --- | --- |
| 空间、场景空镜、状态图 | [场景](工作台/模块/场景.md) | 16:9 无人；既有空间编号；Snn 依获认可基础图编辑 |
| 人物、服装、群演 | [角色与群演](工作台/模块/角色与群演.md) | Cnn-Lnn／Gnn；16:9 正式板；9:16 独立审美试装 |
| 物件与多视图 | [道具](工作台/模块/道具.md) | Pnn；4:3 白底多视图；先判断独立制作价值 |
| 剧集主封 | [封面](工作台/模块/封面.md) | 3:4；准确完整英文剧名；必要人物身份信息 |

默认写实仿真人；明确要求或当前剧已确认动画时，才按需读 [可选风格分支](风格项目/明亮写实卡通/README.md)。各模块画幅、空镜、空手、白底等条件分别使用。

[共用设计方法](.agents/skills/drama-image-prompts/references/visual-design-foundation.md) 帮助观察、构思和取舍，不是必须填满的长表格。`设计参考/` 与风格资料按需使用；`项目记忆.md` 定向查偏好和反馈；历史案例不自动成为新设计配方。

## 剧目资料与成果

只有进入具体作品的制作任务时，才使用 `剧目/` 的剧本、解读、资产、状态与反馈。独立设计无需建剧目目录。新剧需要保存整剧资料时可复制 [新剧目模板](模板/新剧目/)，保留原始输入；[事实账模板](模板/新剧目/01_共享事实账模板.md) 用于解读与跨资产复用，单张任务只记录必要事实。

模板内部链接指向同批复制文件，规范从工作台入口读取。当前任务记录区分 **提示词已完成、图片已生成、用户已认可**。反馈先实际看图，再区分设计选择、提示词表达与生成执行；单剧事实留在本剧，稳定跨剧经验才进入项目记忆。保留旧稿并标明替代版本，不无故移动历史成果。
