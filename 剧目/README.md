# 剧目资料入口｜只进入用户指定的作品

这里保存具体作品的剧本、已有解读／事实账、资产、参考与反馈；设计方法与规格从根工作台及当前模块读取。独立文字／参考图／局部设计不需要进入本目录。未指定剧目时，不按修改时间、下表顺序或旧待办猜测当前作品，也不自动借用某剧的人脸、季节或造型。

## 怎样读取

1. 对应用户给出的名称；名称不明确且影响结果时询问，不遍历全部剧本猜测。
2. 先看该剧状态中当前有效文件和已确认输入，检查版本、覆盖范围与认可状态，再读本轮所需资料。状态可能混有旧进度，不能仅凭“当前”二字断言最新；冲突回查相关原文和用户决定。
3. 首次完整剧本制作任务通读全文并保存可复用解读；后续核实解读对应版本、覆盖范围及相关原文。单张约束任务只核验有关身份、事件、地点、编号等，不声称读过未读取全文。
4. 有用户资产表保留来源映射；整剧范围由用户确认后分批制作。单剧事实和反馈留本剧；跨剧经验仅按需调用。
