## 调用方法

1. 用户已选动画后，先确定当前模块。场景可调用AN-00既有场景核心；道具和角色使用AN-00新增的跨模块媒介核心。
2. 按剧情选择AN-01或AN-02。两卡既有完整英文核心仍是场景组合词，已含公共基线；通常直接复制即可。道具／角色只提取相关世界工艺和色材，不照搬建筑座位条款。
3. 按地点添加装修等级、时间天气、情绪光影与中等细节模块。贵族装修只用于真正权贵空间。
4. 写正式场景时补入固定16:9、实际功能、机位、参照物、路径、4–8个材质Hex和空镜硬限制。风格块本身不替代这些内容。
5. 成图反馈分别记录为方向认可、用户报告与实际图像检查。没有逐图证据时不写全部成图通过。

## 共同约束

- 正式英文用原创可见设计，不用现有作品、工作室、角色或标志性建筑名。
- 不因风格词新增法术、监控室、人物身份或剧情事件。
- 暗部有颜色、动作物可读；不是统一全亮或全暗。
- 剧情需要逐一指认的座位保持颜色／位置区别；不把所有房间改成彩色椅子展厅。
- 物件数量服从动作、生活功能和空间规模，没有全剧通用上限。
- 历史规则仍按原来源维护：[场景模块](../../工作台/模块/场景.md)、[公共动画定调](../明亮写实卡通/场景风格定调模块.md)。本库只整理风格选择和可复制模块。
