## 目前的角色视觉基线

- 原创、高品质、明亮的三维动画拟人动物；动物头骨、口鼻、耳角、爪蹄、尾翼和体态在整体剪影中可辨。
- 眼眶和眉区适度动画化；按具体人物设计视线、眼睑、眉形、口鼻变化、耳尾和站姿的连贯表演，不统一放大眼睛或套用物种性格公式。
- 毛发兼具大块方向性毛束和局部细丝；服装、发型与非人形体真实接触。角色材质和光色与已认可的动画场景属于同一世界。
- 不套用主模块的真人九头身、族裔选角或实景摄影语句；主模块的仿真人角色规则不因这里的学习发生变化。

## 生产顺序

`文字身份卡 → 兽脸近景定锚 → 基础皮毛形体定锚 → 单人服装验证 → 16:9 正式服装板 → 场景合流验证`

正式服装板沿用项目原规则：默认 16:9、纯白 `#FFFFFF` 背景，**左侧高清兽脸放大，右侧依次为正面、严格 90° 单侧面、背面三个完整全身视图**。用户参考图只用于学习角色风格，不改变版式；每条角色提示词正文仍须自行写明画幅。首张原创定角图得到用户认可后，才成为后续换装与跨镜头的身份参考。

跨模块仍禁止宗教元素、第三方品牌、商标和可识别 LOGO。没有新剧本或独立角色简报时，先维护方法，不凭参考图发明角色剧情与服装资产。
