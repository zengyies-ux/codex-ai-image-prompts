# 明亮写实卡通｜拟人动物视觉分支

本目录是现有短剧视觉资产工作台的**可选风格项目**，不是某部剧的资产目录。用户以《疯狂动物城》说明期望的方向，并进一步确认：默认角色是有动物物种特征、以类人方式站立、穿衣和生活的拟人动物。正式提示词和成品必须建立原创角色与原创世界，不把参照作品的名称、角色、服装、城市地标或具体画面当成生成指令。

## 入口与范围

- 任务明确要求“写实卡通”“明亮三维动画”“拟人动物动画”等方向时启用。未指定时继续使用项目原有的写实仿真人风格。
- 先按根入口与当前模块分流；剧本、项目记忆和案例按需读取。本目录只替换视觉风格与动物形体，不给独立设计增加全剧前置，也不替换资产取舍、编号与交付规格。
- 默认只写提示词，明确要求才生成图片。充分的独立需求或参考可直接设计；涉及指定剧目时核验相关事实，不凭空编造剧情。
- 当前剧目定稿后的物种、外貌、空间、色板和已认可图片写入该剧目的 `剧目状态.md`，不写回本目录成为所有剧目共用设定。

## 文件

- [风格规范](风格规范.md)：视觉定调、角色／场景／道具／封面适配、原创性检查与质检。
- [提示词模板](提示词模板.md)：可填的英文结构与一条通用风格锚句；模板不是具体剧目的最终提示词。
- [场景风格定调模块](场景风格定调模块.md)：将已认可的动画场景视觉方向拆成画面媒介、建筑形状、色彩、材质、光影、物种尺度与情绪覆盖，可按剧情拼装。
- [动物动画风格数据库](../风格数据库/README.md)：共同CG媒介、已认可的魔幻蒸汽与现代都市温馨方向；附场景核心、道具适配、中等细节及分项证据状态，动物配角仅定角准备。
- [研究依据](研究依据.md)：公开制作资料和从中提取的方法。资料用于理解设计机制，不用于复刻画面。
- [拟人动物角色定调](角色定调/README.md)：已保存并分析用户提供的 14 张角色参考；记录兽脸表演、物种结构、统一动画质感和先定脸形体再做服装的流程。具体角色的成图与认可状态只查其剧目状态。

## 生产顺序

独立任务：`需求／实际看参考 → 必要原创设计锚点 → 当前模块提示词`。

整剧任务：`首次通读／核实已有解读 → 用户确认资产范围 → 原创世界锚点 → 分批提示词`；真实反馈按图像证据回写本剧。

初次制作某剧时先确定原创的城市生活逻辑、物种尺度方案、建筑与道具的共同形状语言、主色板和材质家族。若本轮同时制作场景与角色，可先用一张实际有剧情用途的核心场景和一位需要持续识别的角色验证风格，再扩展同剧资产。此验证不自动增加“展示专用”资产。
