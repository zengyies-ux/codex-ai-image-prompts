# 研究依据与方法转译

用户以《疯狂动物城》作为理解视觉方向的参照。下列资料来自制作方公开页面；它们用于提取一般设计机制。本项目的正式提示词不使用该作品、工作室或角色名称，不复刻其具体设计。

| 来源 | 可核实内容 | 本项目的转译（推论） |
| --- | --- | --- |
| [Walt Disney Animation Studios：角色与世界制作论文](https://www.disneyanimation.com/publications/from-armadillo-to-zebra-creating-the-diverse-characters-and-the-world-of-zootopia/) | 不同体型的动物会改变建筑、交通和道具的尺度设计；角色毛发和环境需要在远近景保持可读。 | 每部新剧先建立自己的物种与尺度规则；门、座椅、工具应能被角色实际使用。无需复制影片的城市分区或物种组合。 |
| [Walt Disney Animation Studios：Lighting](https://www.disneyanimation.com/process/lighting/) | 制作方描述了自然色与明亮光线的基础视觉状态，以及随情绪变化的灯光策略。 | 本分支以清晰、明快的光色为基线，但剧本夜景和冲突场面仍按情绪调整，并保留光源依据。 |
| [Walt Disney Animation Studios：Visual Development](https://www.disneyanimation.com/process/visual-development/) | 视觉开发用角色、世界、色彩和构图承载故事主题。 | 提示词先定剧情焦点和关系，再定色板与细节。 |
| [Walt Disney Animation Studios：Modeling](https://www.disneyanimation.com/process/modeling/) | 角色与环境模型需要同时具备造型吸引力、重量感和故事功能。 | 使用设计化轮廓与可信体积，不把“卡通”简化为所有物体都变圆。 |
| [Walt Disney Animation Studios：Look Development](https://www.disneyanimation.com/process/look-development/) | 材料通过形状、颜色、纹理、反射和毛发细节共同建立。 | 在角色、场景、道具提示词中分别写材料响应和接触关系，避免统一塑料感。 |

这是一份风格方法研究，并非对某个具体画面的授权或相似度结论。后续用原创剧本和实际成图反馈修订本规范；没有生成图之前，不把模板效果记为已验证。
