# 明亮写实卡通风格规范

## 1. 视觉定义

本分支交付**原创、明亮、具有鲜明卡通感的高品质三维角色动画画面**。先让大形、轮廓、比例和色块表现出动画设计，再用可信体积、接触与光照支撑空间。动画化必须在缩略图中看得见，不能只在写实建筑上加一点圆角。明亮是基础气质；夜景、雨天或冲突场面仍服从剧本，但保持形体可读、色彩层次和清楚的视觉焦点。

2026-09-23 的公寓入口与电梯厅实际成图暴露了一个明确失败：虽然提示词写了 `3D animated`，大量真实石材纹理、细小磨损、金属反射、具体焦段与“轻微风格化”表述仍把画面推成高档楼盘效果图。今后场景提示词以**造型设计 → 色块节奏 → 动画材质 → 光影 → 少量真实细节**的顺序书写；写实细节只辅助，不主导画面。第三张轿厢没有用户提供的成图，不能把它的效果当成实测结论。

用户已明确认可第二轮提示词的**动画风格定调**，并要求后续公寓空间沿用。这个确认锁定设计方向；第二轮具体图片若未提供，仍不记录为已核验的出图效果。

用户随后指出：仅在文档参数处写 `16:9` 不足以让单独复制的提示词锁定画幅。此分支的每条**场景英文提示词第一句**都明确写 `A fixed 16:9 landscape frame...`，同时在生成器设置中选择 16:9 横图；后续构图按横幅完整宽度组织。公寓 A01–A06 已按此修正。

具体落点：

- **形状**：建筑主体要有明显的原创剪影、经过设计的层级与体块节奏；门、窗、阳台、扶手可适度放大或拉长，曲线与斜线形成方向，同时保留承重和通行逻辑。既不堆动物符号，也不把一切变成圆胖玩具。
- **材料**：用较宽的哑光色面与少量可辨材质区分石、木、陶、金属和玻璃。近景可有柔和的手工感或纹理，但避免密集真实纹理、摄影级反射与满画面微细节压过造型。
- **色彩**：比实景方案更大胆地组织暖冷、浅深和饱和度。大色块负责空间层级，较亮的强调色集中在入口、动线或操作区；阴影可以带蓝紫、青绿等设计性色相，但仍服从光源。
- **光线**：有明确的太阳、天空、窗户或灯具来源；光照可以更柔和、更概括，明暗边界和色彩反弹经过美术设计。保留空间体积与接触关系，减少楼盘广告式的镜面高光和过曝大理石。
- **镜头**：仍写清位置、方向、前中后景和动作区；优先展示建筑剪影与空间故事。具体毫米焦段与摄影机高度只在确有构图作用时写，避免每张图都变成写实房产摄影。

英文风格锚句可按剧情改写：

> An original high-end 3D animated world with expressive sculpted silhouettes, clearly stylized architectural proportions, broad coordinated color planes, softly painted material texture, luminous color bounce, and graphic yet spatially coherent shadows.

这句话只是公共基线；每条正式提示词仍须写清剧本地点、功能、结构、角色或物件的独有设计。

## 2. 先建立原创世界的连续性

每部剧只建立一份简短世界设计卡，不跨剧套用具体设定：

1. **地点与生活**：国家／城市、季节、气候、社会层级、交通和职业环境，来自剧本或标明的合理假设。
2. **物种范围**：哪些角色是什么动物；物种服务人物与故事，不把物种当成性格公式。
3. **尺度系统**：角色身高差、门把手、台阶、座椅、交通工具和手持道具如何实际匹配使用者。只有剧本需要多种体型共同生活时才设计多尺度设施。
4. **形状语言**：选两至三个可重复的原创几何关系，例如斜切拱形门框、竖向分段立面、叶脉式遮阳片；不要借用参照作品的标志性街区和建筑组合。
5. **色材系统**：主色、辅色、强调色；建筑／服装／道具共享材质与光照逻辑，而不是全部同色。
6. **标识系统**：只使用剧情确需的虚构名称与原创图标，先确认准确文字，再跨资产统一。

同一剧目的角色、场景、道具和封面共享上述设计卡。不同大场景可以改变天气、等级和色彩权重，但保持同一世界的物理与美术逻辑。

## 3. 场景 A/B 与状态帧

资产粒度仍是可复用的功能空间底板：A01 为有实际剧情用途的母版，A02 起为必要功能延展，B01 开始独立大场景。相同空间只变时间、天气或灯光时默认复用；确需状态帧才用 `<基础空间ID>-Snn`。Snn 只在基础成图获认可后预写编辑提示词，实际编辑必须以上传的基础成图为唯一图像参考，并锁定机位、结构、固定家具、材质和位置。

场景提示词按“固定 16:9 横构图 → 动画画面身份与主剪影 → 相机与构图 → 前中后景／动作区域 → 建筑形状及种属尺度 → 大色块和少量叙事细节 → 有依据的光源与动画材质 → 材质绑定的 4—8 个 Hex 色值 → 必要限制”书写。默认空镜，既不出现人，也不出现拟人动物、剪影或人形／动物形反射。开头和结尾都要明确三维动画的造型与渲染语言；已反复出现的“楼盘效果图”问题，可增加一条针对性的非摄影写实限制。

2026-10-01 用户进一步要求场景的卡通亲和感**克制地增加一点**：从略柔和的轮廓、适度夸张的门窗与家具比例、少量有节奏的不对称、协调饱和色面和柔化材质入手，保留承重、通行与使用逻辑。庄严或压迫空间仍按剧情保持结构秩序；不把所有家具做圆胖、满屋加动物符号或改成幼儿游乐园。该调整只针对本分支场景，不改角色外貌。

场景优先服务后续表演：必要参照物有稳定的颜色／轮廓／空间位置，重复家具减少并分开，核心功能物与动作区在画面中清楚可读。灯光与构图加强层次，不能用更多摆设、更多灯具或全局提亮代替。具体执行维护在场景提示词标准，不给所有空间套同一物件数量或彩色座位配方。四张用户实图及判断见[场景参照物与减法反馈](../../设计参考/2026-10-01_场景参照物与减法/反馈学习.md)。

2026-10-02 用户将场景细节调整到中间值：动作参照物分色与稳定位置继续保留，功能家具、织物、陈列和成组生活信息恢复到次级区域；建筑层次与有源光影增添美感，动作区和通路保持清楚。数量按功能与容量确定，不设统一硬上限。

## 4. 角色 C/L 与群演 G

此分支的拟人动物角色默认按“自主设计命名配角”的方式建立原创身份。用户 2026-09-24 提供 14 张参考并确认**先定兽脸与基础形体，再做服装板**；完整分析与原图索引见 [角色定调/参考图学习与角色定调.md](角色定调/参考图学习与角色定调.md)。这些图是风格研究，不自动成为本剧人物脸模或可复刻造型。首张原创定角图获用户认可后，才把它锁为后续换装与跨镜头的身份参考。用户若指定某张图为该角色的身份参考，则按指定参考锁定。**真人主模块的女主、男主、男二、女二控脸前置条件不因此改变。**

默认主体是**类人拟人动物**：能直立、说话、穿衣并完成剧本动作，同时保留准确可辨的物种特征。设计顺序为“剧本身份与动作 → 物种选择或已确认物种 → 头部与全身轮廓 → 面部表演区 → 皮毛／皮肤／羽毛 → 服装和鞋履 → 同剧风格统一”。

- 物种识别写进耳、口鼻、眼周、颈部、尾、爪／蹄／翼和体型结构；不能只在普通人身上贴一对耳朵或尾巴。
- 眼神与表情要可表演，但不统一放大到幼态。年龄、职业、阶层、性格和剧情阶段仍通过轮廓、神态、服装与维护状态区分。
- 角色比例由物种与角色身份决定。**真人九头身及其头腿数值不作为本分支默认约束**；写清该角色自己的头身关系、重心、四肢长度、手部／爪部功能和尾巴如何与服装互动。
- 皮毛、羽毛或鳞片有方向、密度与局部变化；服装与身体接触有厚度、压痕、遮挡和重力。避免毛发像绒玩具、衣服像贴图。
- 新拟人动物角色可以自主设计原创面部，不要求先提供真人脸模。若用户提供或确认了该角色的专属动物身份参考，则锁定物种、兽脸结构、毛色花纹与固定识别点；仅有人类脸模时，不擅自推断其动物物种或最终兽脸。第一张原创角色图获认可后，它成为后续换装的身份参考。
- 用户上传实际成图并指出问题时，默认把图片作为**分析材料**，修订原生文生图提示词。只有用户明确要求上传／使用参考图、图片编辑或以图锁身份时，才写依赖上传图片的提示词；不能因为看过成图就自动切换到图片编辑流程。
- 角色先完成兽脸近景和完整基础皮毛形体的确认，再进行单人服装验证。基础形体采用非性化的中性展示，不刻画裸露解剖细节；每条提示词在正文自行写明画幅。
- 正式独立角色板**沿用项目原版式**：16:9、全白 `#FFFFFF` 背景，**左侧高清兽脸放大，右侧正面、严格单侧面和背面全身**。用户图 05／06／09 的版式只作参考，不改变制作规则。视图之间锁定物种、脸部结构、毛色花纹、耳尾、服装和允许配饰。群演仍用 `G01` 等组图，人数与身份需求沿用主技能；用户的多物种群像只用来研究尺度和统一风格，不继承其人数与服装。
- 服装仍依据地点、气候、职业、阶层和剧情动作设计，保留一条中景可读的主设计关系；处理耳、角、尾、翼和爪对领口、帽饰、裤裙、鞋履的真实穿着影响。原项目对女装胸部稳定覆盖、手部空置和允许随身装饰的限制继续适用，除非用户明确另定角色板规格。

## 5. 道具 P

沿用 4:3 白底多视图：一个完整主视图、两个有效辅助视图和必要特写。道具尺寸与握持部位服从使用角色的爪、蹄、翼和身体尺度；形状可比真实商品更清楚、更有节奏，但开合、连接、重心与接触仍可信。把剧情要求的磨损、破损、签署或证据状态画准。通用道具优先复用；文字仅保留剧情必须读懂的内容。道具色材、原创图标与同剧场景统一。

## 6. 封面

默认 3:4。先从完整剧本提出 2—3 个在主角位置、关系动作、构图骨架或光色策略上真正不同的概念，再写选定方向的完整英文提示词。第一眼看清主角的物种、身份和情绪；第二眼读出人物关系；第三眼看到一个关键剧情符号，同时准确读出英文剧名。封面人物使用已确认的原创动物角色参考，不在封面阶段重新发明核心角色外貌。角色与环境接受同一光源，不出现贴图式拼接。

## 7. 原创性与交付检查

- 正式英文提示词不写参照电影、工作室、现有角色名，也不用 `in the style of ...` 代替可见设计。
- 不复刻参照作品的角色组合、制服、专有地名、徽章、车辆、店招、建筑地标、场景构图或剧情桥段。只借鉴“可信材质与光照＋适度风格化形状＋明亮清楚的叙事层级”这类一般方法。
- 各模块继续禁止宗教元素、现实国家国旗／国徽／可识别官方国家徽记、第三方品牌与可识别 LOGO；剧本核验的虚构文字和原创图标可按任务使用。
- 每张图检查：轮廓是否在缩略图可读；动物结构是否可信；尺度设施是否真的可用；光源是否能解释阴影；是否有独立于参照作品的设计锚点；角色、场景和道具是否属于同一世界。
- 区分“提示词完成”“图片生成”“用户认可”。仅有文本时不把风格效果写成已验证。
