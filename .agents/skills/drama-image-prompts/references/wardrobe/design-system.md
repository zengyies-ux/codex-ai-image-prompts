# 角色服装设计系统

更新：2026-09-30。本文件集中维护具体服装的构思、选择、提示词表达与成图改版方法。身份、编号、体型、9:16 试装和 16:9 正式板的规格见[角色资产标准](../character-standard.md)；地点与生活条件按需读[本地化系统](market-localization.md)；构思需要可见语言时查[设计关系词库](style-library.md)；外部方法与来源见[研究记录](research-notes.md)。辅助文件不得重新建立角色制服、饰品配额或另一套设计流程。

## 一、共同目标与证据边界

主要角色服装同时完成**吸引目光、表达人物、可信穿着、资产可复现**。沉稳、内敛、温柔、普通收入或女主身份，均不能成为降低设计完成度的理由。性格决定吸引目光的方式：沉稳角色可以靠有力比例、明确的材料交界、连续线条、个人首饰和有意留白抓眼；高调角色可以放大纹样、色彩反差、首饰尺度或合理露肤。衣服与人物共同建立形象，漂亮脸模不能抵扣服装设计任务。

男主、女主、男二、女二按剧本和同场关系分配注意力。女二可能更主动经营外表，但没有固定的短裙、撞色、豹纹或性感制服；女主也不自动退回普通基础款。剧情需要伪装、低存在感或朴素时，这是有意的角色选择，仍需完成比例、合身度、色材和穿用状态。

本项目实际反馈：自然日常和现代西部约 70 分，短皮衣组合 78 分，两套自主设计均为 80 分。80 分方案的有效关系是暖色与形状呼应，以及甜感材料与厚重工装的宽窄反差；不能直接复制单品。高端酒会和权贵职场仍有失败证据，尚未验证稳定达到 85 分，也未验证上述方法在沉稳女主或男装中的分数。证据入口见[本轮复核](../../../../../设计参考/2026-09-30_服装设计模块复核/诊断与改进.md)与[80 分实际成图](../../../../../设计参考/2026-09-25_自主两套服装验证/成图反馈与规则落地.md)。

## 二、设计开发：先产生方案，再选择和写作

本节是统一执行流程。内部比较用于提高交付质量，不增加用户要求的套数，也不默认增加用户审批轮次。

### 1. 固定完整简报

内部短卡记录：

- 人物身份、年龄、职业、真实收入、性格，以及**她／他希望别人怎样看自己**。
- 地点、年代、天气、行业正式度、场合、动作和剧情阶段；区分剧本事实、用户指定与制作假设。
- 本轮要求的衣服类别、设计强度、同场角色与景别；保留已经认可的单品和硬限制。
- 面部参考、衣橱连续性、用户需要的交付画幅与数量。

每次改版都以这张完整简报为依据。例如“权贵职场＋热辣大胆＋不露沟”必须同时成立；不能因职场而抹掉热辣，也不能因抓眼而失去工作场合。身份脸图只锁身份，不继承原图衣服与发型，不从真实面孔推断虚构人物品性。

缺失信息只有会实质改变造型且无法合理推断时才提问。独立审美测试可标明最小假设后继续；完整剧目制作仍依当前剧本和状态。用户已要求直接提示词且必要输入齐全时直接交付；要求概念时交付概念；需要方向对齐时给简洁中文选项，避免反复确认。

### 2. 实际看参考，拆出可用关系

新方向、陌生生活环境或连续失败时，先建立小型参考板。已有相关、实际看过的参考可复用，不必每套重新大范围搜索。材料覆盖：可信生活／工作穿法，较强设计表达，材料或首饰，以及相关的项目成功与失败样本；只读本轮需要的部分。

每个采用的视觉参考留下短记录：`来源与日期｜实际可见关系｜为什么适合此人｜保留什么强度｜为动作、覆盖或资产制作调整什么`。

- 直接打开并查看图片；搜索摘要、图片说明和品牌名不能证明看过画面。
- 看长度、体量、轮廓边界、纹样密度、表面反光、首饰位置与鞋服衔接，不能只摘抄“高级、热辣、松弛”。
- 生活资料校准可信范围，秀场／展览拓展设计选择；两者都不单独给出角色答案。
- 设计师、品牌、作品名可以出现在研究出处，最终提示词使用原创可见语言。

研究的规模按任务决定。需要本地化证据时至少交叉核对不同类型的来源；已有足够证据则停止扩搜，进入设计。

### 3. 内部提出真正不同的整体方向

为尚未成立的一套造型，通常先内部构思三个候选，每个只需短卡，不先写长提示词。三个是本项目的工作办法，不是时尚规律；简单局部修复或已有获认可主体时可直接调整。

候选要改变整体关系，例如比例组织、服装类别的搭配、材料张力、纹样与静面关系、首饰与领口的组织。同一套衣服换颜色、换面料名称或追加一条珠绣，不算不同方向。每个候选写清：

`可见的整套关系｜第一眼看哪里、第二眼读到什么｜妆发首饰鞋履的作用｜人物与场合依据｜可能失败处`。

所有候选都要回应完整任务。不能把其中一版故意做普通以衬托另一版。最终只交付用户需要的套数和形式；内部候选与淘汰理由无需逐项展示。

### 4. 同步构思整套关系

轮廓比例、色材纹样、妆发首饰和鞋履共同开发，任一项都可触发构思。设计可以来自单品结构，也可以来自熟悉衣物的有意组合。按以下关系推进，而非凑设计点数量：

| 关系 | 实际决定什么 |
| --- | --- |
| 比例与尺度 | 肩、腰、衣摆、裤裙和鞋的长度及体量；首饰相对领口、脸与头发的分量 |
| 焦点与呼应 | 第一眼的吸引位置；其他颜色、线条、五金或材料如何支持它 |
| 节奏与连续 | 横斜纵线、纹样疏密、露边、褶裥与上下衔接如何引导视线 |
| 对比与统一 | 哪种软硬、宽窄、明暗、粗细或类别反差表达此人；什么将反差连成整套 |
| 留白与层次 | 哪些区域保持平静以衬托有分量的部分；外层、内搭与首饰是否遮挡 |

“主设计关系”是一句统领整套的可见关系，不是只能有一个位置、一个结构或一件首饰。多个区域可以有主次地联动；简单造型也可通过轮廓和材质完成，不强制图案、撞色或局部装饰。70／20／10 等比例只可作为尝试，不作固定配额或合格依据。

先检查衣摆、腰线、裤裙和鞋的落点。长裙配靴并非天然不合理，需看裙长、裙量、开口、靴筒、腿部空间、材料与场合；同色厚裙叠同色厚靴可能形成沉重整块，实际失败不能推广为禁用组合。强设计也保持真实衣料重量、厚度、空气层、接触阴影和活动余量。

### 5. 转译时保住有效强度

把参考关系转成符合人物的衣物，分别判断：保留哪些比例、线条、表面或配饰关系；修改哪些不适合场合、收入、行动或胸部覆盖的部分。不要规定每套只能吸收一个轮廓加一个工艺，也不要统一降低体量、装饰和制作成本。

为真实穿着修改结构后，重新检查主要关系是否仍清楚。透视胸片可变为不透明衬里，拖地长度可调整到能行动的长度，首饰可用符合消费能力的材料完成；修改后若只剩普通款，需要重新组织整体。大胆不等于无缝点、漂浮衣片、随机异形袖或无关系拼色。

### 6. 比较候选，分别过三道门

| 检查 | 通过所需证据 | 未通过时优先处理 |
| --- | --- | --- |
| 吸引力与个性 | 去掉“高级／贵气／热辣”等形容词后，可见描述仍有明确选择；胸腰中景与全身各有连贯信息；这套为何属于此人 | 改整体比例、类别、色材或首饰关系；普通主体不要只补花边 |
| 人物、场合与动作 | 服装同时符合人物希望展示的形象、当地生活、资源与本场行为；设计强度响应完整简报 | 修正正式度、材料、长度、闭合或行动余量，并保留吸引力 |
| 生成与资产一致性 | 参考身份清楚，制作画幅与站姿正确，面料能真实穿在身上，胸部覆盖、饰件和多视图规格完整 | 改具体表达、结构可复现性或制作约束，不用表情和摆拍替代衣服 |

自然感达标不能抵扣吸引力缺失，漂亮也不能抵扣场合错配。静态文本阶段只能做预判，不能宣称已经验证或自行给到 85 分。

在已有反馈的方向中，选一个相关认可样本和一个失败样本作机制对照：新方案保留了什么、实质改变了什么、是否仍重复失败公式。只比较相关材料，不遍历历史剧目。没有可比样本时注明“待验证”，不强行类比。

把核心角色放进同一场戏横向检查。可共享职业单品、家族材料或城市习惯，但需要让角色选择和视觉层级可辨；不强制四个维度全改，也不要求每人独占一种风格。女二的抢眼与女主的吸引力可以同时成立。

### 7. 选定后才展开提示词

将选定关系写成具体位置、尺度、材料和穿法，删去候选中未采用的细节。主关系早写，承担主焦点的首饰跟随该关系，不被埋在末尾。完整正文能独立复制，不能靠读内部分析才知道衣服长什么样。具体顺序见第六节。

## 三、按人物选择表达方式

- **沉稳／内敛**：在平静色面中建立有力的体量、长短、材料差或首饰轮廓；克制的是表现方式，设计选择仍清楚。低饱和与小耳环本身不能证明设计成立。
- **高调／对抗／热辣**：从人物的自我展示动机选择放大变量。肩颈、腰部、腿部、纹样、光泽或首饰可形成张力，不依赖乳沟，也不把短、紧、亮同时叠满当答案。
- **富裕／权贵**：购买资源与表现欲是两个变量。合体度、衣物选择、做工、材料与首饰共同表达；世代富裕也可能张扬，新贵也可能克制，昂贵面料名称不能替代设计。
- **职业角色**：先确认行业、职位和自主着装程度；“办公室”不自动等于常规西装裙，“热辣职场”也不自动等于服务制服、夜店装或短裙。让职场可信与人物欲望同时可见。
- **普通收入／年轻日常**：通过可负担、可复穿的单品形成明确比例与个性，不以昂贵珠宝救场，也不因预算降低设计。未成年角色保持适龄。
- **男性角色**：通过外套与裤的体量、领口层次、织纹、穿法、鞋楦和允许饰件形成选择；不能直接套女性成功组合或认为男装无需设计。

普通白衬衫与黑裤、针织与半裙均可成为好造型，关键是整套如何组织；不强制改造两处结构。单色长裙或长外套可以用形态、材料和留白成立，也可以需要纹样或层次，按实际整体判断；不得一律追加拼片、滚边或渐变。

## 四、胸部覆盖与制作边界

所有女装在正面、侧面、背面、面部放大及自然动作下均无可见乳沟、侧胸、胸部透视或滑落／扣眼绷开的风险。完整不透明衬里、稳固肩带与腋口、足够胸部覆盖、闭合与固定胸片要成为真实结构。可按人物设计肩、手臂、背或腿部，不能用统一高领、厚重冬装或夸张胸部体量代替覆盖设计。

提示词先写该件衣服实际的领口高度与形状、内衬和固定方式，再保留简洁硬限制：

> The bodice securely and opaquely covers the bust from the front and side in every view and natural movement, with no visible cleavage or side-bust exposure.

发型、首饰默认范围、空手站姿、体型与板式统一遵守[角色资产标准](../character-standard.md)。主要角色默认饰件为手表、耳环、项链和头饰／发饰；用户已指定的特殊例外按当前任务执行。不能用包袋或手持物补足设计。所有衣物、鞋、首饰无可识别第三方品牌和宗教元素。

## 五、妆发、首饰与角色衣橱

发型按人物自我呈现、领口、耳饰和剧情决定。高马尾、披发、短发、盘发、低束均可；资产板的一致性要求不决定发型高低。露出或遮住哪一段肩颈、是否显示耳饰、发量与衣领是否竞争，应在整体构思时确定。妆容保持身份和真实皮肤，不用换脸或强表情代替服装的个性。

首饰可以是主焦点、反差、呼应或连续身份记号；尺度由人物和镜头决定，不固定成小耳环细手表，不限制耳饰与项链二选一。把形状、材料、长度、所在位置写清，检查是否被领口头发遮住。多个饰件要有作用和主次，减少无关堆积。

每个主要角色建立简短衣橱 DNA：常用比例与轮廓、色域、主要材料、鞋履与首饰偏好、妆发状态、消费与维护习惯、复穿衣物。记录稳定项与当前场次变化，无须机械规定颜色或材质数量。角色成长改变可见选择，又保留身份连续性；“掌权”不一律变深色硬肩，“低谷”不一律变脏乱破旧。复穿、自然折痕和旧款需有生活依据。

## 六、提示词表达与交付

1. 核心控脸角色先写身份参考的用途；自主定脸配角先定义身份。写明用户选择的 9:16 全身试装或正式 16:9 板式、全白背景与中立站姿。
2. 按剧本与角色资产标准写体型；用一句可见比例、色材或搭配关系概括造型，包含主焦点的饰件。
3. 依整体关系描述外层、上衣或连衣裙、下装：衣长、领肩袖、腰线、开合、裤裙结构、材料重量、颜色与纹样位置。顺序可随实际层次调整。
4. 写发型、妆容、首饰与鞋的具体作用；描述真实垂坠、穿着松量与接触关系。衣物反差必须在布料与结构中实现，不能变成平面拼贴。
5. 多视图时写同一造型的正面、单侧严格 90°、背面、高清面部一致性；按当前资产规格保留必要体型约束。
6. 结尾保留胸部覆盖、无品牌、无宗教等硬限制。内部研究、场景背景故事和审查记录不塞进英文正文；只有影响画面的地点／季节／场合信息转成可见衣物选择。

避免用 `subtle / barely visible / restrained / low-contrast` 连续缩小所有主关系；这些词只在确实需要的部分使用。也不以“高级、极致、惊艳”等评价词堆叠替代具体设计。身体比例数字按资产规格使用，不在设计层强制所有外套停在高胯；衣长由当前造型与可见身体比例共同确定。

用户明确要求生成图片才调用出图；默认交付可复制提示词。概念、提示词完成、实际出图、用户认可与正式资产锁定分别记录，不能相互替代。

## 七、成图反馈与改版

看到实图后分清失败层级：

- **设计选择**：图忠实实现了普通或错配方案，回到候选开发，不能归咎生成器。
- **提示词表达**：选定关系在文字里被弱化、互相冲突或埋没，重写位置、尺度、材料和主次。
- **生成执行**：文字明确但模型漏饰件、改衣长、破覆盖、穿插或摆拍，修正该执行问题，保护已经成立的设计。

反馈记录为：`用户评分与原话要点｜实际可见证据｜保留项｜失败层级｜本轮改动｜仍待验证项`。有好评的单品可保留，坏的整体需重组；增加装饰不是每种失败的通用修法。丝袜、靴子、盘发、深色或某类衣服的一次失败不能变成永久禁用。

交付前最后检查：完整任务是否满足；整套可见关系是否成立；全身与胸腰中景是否连贯；人物、场合与关键动作是否可信；身份、站姿、多视图、覆盖和饰件是否合规；同场角色与既定布景是否有层级。检查结果是预判，效果与分数以实际成图和用户反馈为准。
