# 服装设计关系词库（辅助构思）

更新：2026-09-30。词库提供可改变的变量、组合关系和设计提问，男女角色均可按人物采用。构思与选择统一执行[设计系统](design-system.md)；当地生活判断见[本地化系统](market-localization.md)。本库不按城市、阶层或男女主身份自动分配整套衣服，也不把某种材料或发型当成已验证的高分答案。

## 一、让熟悉衣物发生有意关系

| 设计变量 | 可尝试的操作 | 看什么才能判断成立 |
| --- | --- | --- |
| 长短与体量 | 短外层与长内层；窄上身与宽下装；宽外层与清楚腿部线条；长线与一个明确截点 | 衣摆、腰、裆、膝、鞋之间是否有意组织，是否出现拖沓或割断 |
| 衣身与身体的空间 | 肩部支撑、离体领口、贴合与放松的交替、软垂与挺括的边界 | 真实缝点、重力和行动余量；不会成为漂浮衣片或真空贴皮 |
| 材料表面 | 粗织与平滑、绒面与微光、细蕾丝与厚丹宁、干爽棉与柔皮 | 材料差是否在镜头中读出，与人物资源和天气是否相容 |
| 色彩关系 | 近似色中的明暗；互补或冷暖张力；大静面与较强区域；鞋饰与衣服的跨位置呼应 | 颜色有作用和主次，不能依固定面积公式或无缘由拼色 |
| 纹样与静面 | 纹样尺度、疏密、重复、边界、沿裁片分布，搭配平静材料 | 图案是否落在衣物上，是否有中景信息和留白，是否覆盖主体比例 |
| 类别相遇 | 运动与剪裁、浪漫与工作装、柔软与防护、复古与当代 | 反差为何属于此人；是否仍像真实购买、搭配、使用的衣服 |
| 首饰与领口 | 项链曲线呼应领线；耳饰形状与肩线关联；较有分量饰件由静面承托 | 形状、位置、尺度与材料是否被看见；有无遮挡或无关竞争 |
| 穿法与层次 | 门襟开合、领袖露边、内外衣长、塞入与自然松量、重复单品的不同穿法 | 功能与接触关系清楚；无插袋或摆拍也成立 |
| 鞋服衔接 | 裤口与鞋面、裙摆与靴筒、跟形与衣物体量、颜色与材料连接 | 是否适合走坐与当前场合，腿部线条是否沉重或断裂 |

这些操作是试验变量，不能从每行各选一项组装成造型。先决定人物表达与整套关系，再选择有作用的操作；基础衣物通过穿法、比例和首饰也可完成设计，无须凑裁片、扣件或装饰数量。

## 二、人物问题替代角色制服

| 人物或任务 | 优先问的问题 | 可发展的机制，需结合实际简报 |
| --- | --- | --- |
| 沉稳、内敛 | 她／他愿意被注意到哪一部分？哪些选择显示自信而无须炫耀？ | 连贯长线、精确体量、单色表面差、明确但有主次的首饰 |
| 热辣、高调 | 她经营哪种形象？魅力、压迫、反差还是有意冒犯？ | 露肩与稳定胸部覆盖、窄宽或长短张力、强纹样与静面、个人饰件 |
| 财富或权势 | 实际资源与想展示的资源是否一致？着装自主权有多大？ | 材料完成度、合体与维护、主动选择的轮廓／颜色／首饰；安静或张扬均可能 |
| 职场 | 行业、职位、见谁、做什么、场合正式度如何？ | 在真实行业边界内改变比例、穿法、材料与个人标记；不默认西装裙 |
| 年轻日常 | 社群、预算、购买渠道、惯用鞋与复穿偏好如何？ | 熟悉类别的有意搭配、可负担饰件与独特穿法；未成年人适龄 |
| 高端酒会 | 具体礼仪与主办方是什么？她来融入、竞争还是宣示？ | 长度、材料、领肩、首饰与发型共同组织存在感；不靠面料名称证明贵气 |
| 外勤或旅行 | 行走距离、气候、转场、驾驶、携物和工作动作是什么？ | 可活动的鞋服比例、可脱卸层次、耐用材料；板中空手依然有完成度 |
| 低谷或新阶段 | 哪些原有选择仍保留，哪些变化对应剧本事实？ | 复穿、维护、层次、穿法与色域的连续变化；不按状态固定降饱和或变脏 |

女主／女二、男主／男二是叙事位置，不是服装种类。对照同场角色时可以共享职业或世界观特征，由个人选择和画面层级分出身份。

## 三、克制与大胆的开发练习

以下只示范操作，不是完整穿搭或提示词模板：

- **平静色彩，清楚形态**：保持窄色域，试验衣身空间、外层与下装体量、领线和首饰轮廓；比较哪个在胸腰景别最有力。无需改成鲜色才能成立。
- **熟悉单品，清楚反差**：保持可信衣服类别，只改变长短宽窄、软硬表面或饰件尺度的关系；比较是否仍普通，是否有个人选择。
- **图案有分量，其他部分支持**：先决定纹样的尺度和位置，再让平静色面、领口与鞋饰支持它；不要为了丰富同时塞入无关图案。
- **首饰主导**：从一个符合人物的项链或耳饰形态出发，反推领口、发型和衣物材料；不固定耳饰与项链二选一，也不默认为小点缀。
- **没有露沟的热辣**：试验肩、腰或腿部的露肤与包裹、体量、材质和首饰之间的张力；胸部结构稳定、不透明，人体体量依角色规格。
- **职场中的个人野心**：保住行业正式度与动作，比较比例、材料、穿法或饰件如何显示她主动经营外表；避免把“职场”自动转成常规套装。

任何练习若缺人物和场合依据，只保留为研究草图，不直接进入正式资产。
