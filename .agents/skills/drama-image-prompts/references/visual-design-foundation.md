# 短剧视觉资产美术设计底层框架

本文件服务场景、角色、道具与封面四个模块。四类资产的画幅、信息密度和交付结构不同，但底层判断一致：先决定观众应该感受到什么，再决定第一眼看什么、视线如何移动、情绪如何被光色和空间放大，最后才增加细节。

第一节是共用判断链路；第二至第十节专讲封面设计。场景、角色和道具的资产规格、数量、画幅与交付检查仍由各自模块规则决定。

## 一、统一设计链路

每张图片按以下顺序判断：

1. **意图**：这张图只传递哪一个主要信息或情绪承诺？
2. **焦点**：观众第一眼必须看见谁或什么？
3. **关系**：人物、空间、道具和文字如何围绕焦点形成方向？
4. **情绪**：色彩、明暗、光线、材质、天气和景深如何共同放大它？
5. **验证**：缩小、去色、模糊后，焦点、关系和情绪是否仍成立？

如果一张图在第一步无法压缩成一句话，通常意味着内容尚未取舍；如果后续元素没有服务同一句话，通常意味着画面会杂乱或平淡。

## 二、封面的快速识别与选择方法

封面要让观众在手机缩略图中注意到一个清楚的视觉吸引点，感受到本剧的类型和情绪，并产生与剧情有关的兴趣。构思时先核验剧本的角色身份、关系、关键事实与标题，再为每个概念用三句话回答：最先吸引观众的是什么；它让人感到什么或想问什么；它为什么属于这部剧。单人、静态、极简、双人关系近景、环境式和象征式都可以成立。

从本剧最有力的卖点出发，选择少数互相配合的手段：构图与裁切、人物或空间尺度、表情与视线、距离和动作关系、明暗色块、轮廓与负空间、反常但合乎剧情的象征组合，或清楚大胆的标题排布。动作、道具、多人物、冷暖分区和特定人物占比均不是必需项。不同时间的元素可以象征性并置，但要让画面读作设计性组合，不把它伪装成剧本里不存在的写实事件。

概念间的观看疑问与主视觉组织都应明显不同，可改变剧情卖点、主图形、人物组合或距离、光色与标题结构中的关键决定；同一站位只换背景、配色或小道具不构成新概念。最终提示词只写实际会影响成图的视觉决定，不把以上分析过程原样塞入正文。

## 三、字体不是后贴文字

标题从概念阶段就参与构图。先核准完整、准确的英文剧名，再依据词义、长度、背景和缩略图阅读顺序安排分行、字重、宽窄、间距、位置与对比。同一字族的变化可以完成整个标题；需要更鲜明的类型或情绪差异时，才考虑混合字体、手写、笔刷、金属、渐变或局部穿插。它们都是有条件的工具，没有固定搭配。

### 字体设计检查

- 完整剧名是否准确，是否仅出现一次，是否避免无关文字。
- 字形层级是否与本剧的叙事重点一致；长标题能否合理分行，而非擅自删字。
- 标题是否在画面中有清楚的承载区，并与人物、背景和光照属于同一画面；承载区可以在上、中、下部。
- 缩到目标列表尺寸后，关键字与整体标题是否仍足以辨认；平台裁切未知时给脸和标题留外缘安全区，不承诺任意尺寸都能读清长标题。
- 若使用手写、金属、笔刷或渐变，其笔画和材质是否有剧情、画面或类型依据，并保持字腔清楚。

## 四、主体与关系层级

主体大小是叙事权重的一种表达，可用大小、清晰度、位置、视线、明暗或遮挡建立。比例随概念改变：近脸、远景小人、等大双人和单人留白都有成立条件。人物关系可以由视线、距离、朝向、表情、动作、空间隔断或共同的环境线索表达；静止的并置也可能有张力，关键是观众能读到有意图的关系，而不是把动作本身当作抓眼指标。

服装也是主体层级的一部分：

- 服装依据人物身份、剧情阶段和封面主次确定轮廓、剪裁、材质与色彩；尊重已确认造型。
- 角色间通过服装形成有意图的区别或联系，不机械压低所有配角的饱和度与细节。
- 服装颜色需要连接人物与场景，而非只追求单件衣服好看。
- 材质、受力褶皱与光线反馈须可信。女性服装在正侧、俯仰角及自然动作中都不能露乳沟；吸引力靠设计和人物魅力，不靠暴露程度，也不因此统一退回保守通勤装。

## 五、可选的抓眼手段

下表帮助根据剧本和概念选择手段，不是“某种情绪必须使用某种构图”的对照表。也可以只用其中一种。

| 手段 | 可解决的问题 | 使用前核对 |
|---|---|---|
| 构图与裁切 | 让一张脸、两人间的空隙或局部信息成为第一焦点 | 被裁去的部分是否影响身份和关系判断 |
| 尺度与空间 | 用近大远小、建筑压迫或开阔距离表达权力与处境 | 人物身份是否在缩略图仍可识别 |
| 神态与视线 | 用明确的视线目标、眼部反应和距离表达亲近、误解或选择 | 头部朝向、瞳孔落点与故事关系是否一致 |
| 光色对比 | 用明暗、色相、冷暖或局部饱和度建立焦点 | 是否有可信光源，颜色是否服务剧情而非机械平分 |
| 轮廓与负空间 | 用剪影、遮挡、图底关系或留白形成识别图形 | 图形是否帮助理解人物或标题，而非只做边框 |
| 象征组合 | 将不同时刻的真实剧情线索并置，制造准确的疑问 | 是否清楚是象征而非虚构事件；身份与关键事实是否保持正确 |
| 标题结构 | 用分行、字重、宽窄、位置和必要的字体变化形成视觉重点 | 剧名是否完整准确、缩略图是否足够可读 |

引导线、对称、斜线、圆环、门框或镜像可以使用，也可以不用。只有它们帮助观众进入人物关系、环境或标题时才保留。

## 六、情绪渲染的七个通道

1. **色相**：可表达阶段、关系或类型，也可采用近单色设计。
2. **明度**：高对比位置通常更易成为第一焦点。
3. **饱和度**：大色块或局部强色都可能建立识别度，不规定固定面积配额。
4. **光线**：主光方向、环境反射与色温需要有可信来源。
5. **站位与神态**：距离、朝向、视线、表情和必要动作说明关系。
6. **环境与材质**：故事地点、时代、阶层、建筑尺度、陈设与天气决定可信边界，并为主体和标题提供空间。
7. **剧情道具**：仅在有助于理解剧情、建立图形或产生好奇时加入；可以完全不出现。

选择能共同表达概念的通道即可。曾有单剧封面用空间分界、跨界动作和标题转色获得用户认可；它证明这组手段在该剧有效，不构成其他剧的配方。

## 七、道具的使用边界

封面道具可回答至少一个问题：

- 它属于谁？
- 它改变了什么关系或剧情状态？
- 它是否帮助建立构图方向、尺度或时代？
- 观众若看不见它，是否会少理解一层故事？

如果都不能回答，便不必放入封面。已有重要剧情道具须保持外观与归属一致；普通物件可随封面生成，不需要先按道具模块制作白底多视图。道具数量没有配额，极简人物封面可以没有道具。

## 九、封面提示词组织

完整英文提示词需独立可复制，清楚写出画幅、媒介、参考图与角色的对应关系、主视觉、必要的服装／环境／道具、可信光照、准确英文剧名与标题布局，以及当前画面的硬限制。具体顺序服从概念，单人无道具方案不需要虚构关系角色或象征物；无需把内部分析、评分和所有备选手法写进提示词。

## 十、交付前五项测试

- **三秒测试**：三秒内是否看见概念的主要吸引点，感到预期类型／情绪，并找到剧名。
- **遮字测试**：暂时遮住标题并缩成列表小图后，主图是否仍有图形或关系张力；若只剩普通剧照，重选焦点而非机械加动作。
- **缩略图测试**：缩到手机列表尺寸，需要识别的人脸与标题是否仍足够清楚。
- **灰度测试**：去色后主次和标题是否仍成立；颜色不能替代构图。
- **眯眼测试**：模糊细节后，最大明暗块是否仍指向该概念真正的主视觉。
- **删除测试**：删除任一人物、道具或装饰后，故事是否几乎不变；若不变，该元素应弱化或移除。

## 学习依据

- Adobe 对引导线的总结：线条用于把视线导向主体、建立平衡与叙事；不同方向的线具有稳定、权力、运动、冲突或柔和引导等不同作用。https://www.adobe.com/creativecloud/photography/technique/leading-lines.html
- Adobe 对色彩对比的总结：色相、明暗、冷暖、饱和度、互补色与颜色面积都能建立视觉层级；应先验证灰度结构，再用色彩强化焦点。https://www.adobe.com/uk/creativecloud/design/discover/color-contrast.html
- Adobe 对色板的建议：从单一主色建立体系，并使用主色、辅色和少量强调色控制面积关系。https://www.adobe.com/uk/creativecloud/design/discover/color-palette.html
- Interaction Design Foundation 对图底关系与简化组织的总结：清楚的层级、图底分离和易识别结构有助于快速理解。https://www.interaction-design.org/literature/topics/law-of-figure
