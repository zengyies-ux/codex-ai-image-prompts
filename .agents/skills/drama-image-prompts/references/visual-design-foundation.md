# 四模块共用｜图片设计与提示词方法

这里提供选择与修正办法，不增加资产规格、固定候选数或审批。各模块的画幅、空镜／空手／白底、身份与连续性仍读自己的规范。封面的字体、关系与缩略图细则维护在 [封面标准](cover-standard.md)，历史研究维护在 [灵感与证据](cover-inspiration-and-cases.md)，其他模块不必加载。

## 轻量设计过程

**理解用途与必要条件 → 观察具体视觉关系 → 构思整体方向 → 比较取舍 → 写成清楚提示词。**

- 先明确观众或制作要感受到什么、第一眼看什么、怎样使用这张图；剧情仅核验当前任务相关事实。
- 开放设计中，用户明确要求强设计、新颖或抓眼，或连续反馈方案普通、缺少新意时，应先在内部比较有实质区别的整体组织再取舍；其他任务按实际缺口决定是否探索。不固定数量、不强制展示所有候选。换色、昂贵材质名称或加一件饰品不自动构成新方向。用户只要一套就交付一套，低复杂度任务可直接构思。
- 从意图、焦点、关系和情绪判断元素怎样配合：轮廓与比例、色块、轻重与材质、距离、空间、光线或文字。不要求每张图只表达单一情绪，也不机械加入动作、撞色、道具或装饰。
- 选择服务用途、整体关系成立且符合必要约束的方向。局部修复、忠实反推与已获认可方案保留有效设计，直接处理缺口，无需重新探索。
- 最终正文写可见设计决定、必要参考映射及硬限制；少用空泛风格标签，不把思考记录、评分和未选方案塞进提示词。

## 使用图片参考时

必须实际打开使用的图，不能拿文件名、文字描述或搜索摘要代替观察。按参考职责留下少量准确记录，通常几句话足够：

1. **所见证据**：具体长度与体量、位置与层次、色块、材质、轮廓、光源或空间关系。区分能看到的细节和推断；看不清的材质、背面或结构不伪称已知。
2. **关系解释**：哪些部分怎样相互加强或抵消，为什么可能有效；说明不确定性。不是给参考贴“高级”“美式”等标签。
3. **本次转译**：保留什么，为用途或审核调整什么；改变后原来的轻重、层次、焦点或情绪是否仍成立。

用户明确要求反推／还原所提供的参考图时，可以忠实保留整套服装或画面的可见设计关系；融合／改版时才按要求重组。用具体轮廓、比例、结构、色材和搭配描述，不用品牌／作品名代替设计；第三方标识、宗教、现实国家标识及女装胸部覆盖仍按共同限制处理，并说明必要调整。独立原创任务不机械照搬历史案例的整套答案；身份图只锁必要身份。没有图也可从需求自主设计，无需强制寻找成功例。

## 按模块判断

| 模块 | 主要判断 | 提示词中落实 |
| --- | --- | --- |
| 角色与服装 | 整体搭配、人物魅力与生活／场合适用性 | 长短宽窄、层次、鞋服与妆发配饰关系，真实受力与覆盖结构 |
| 场景 | 空间性格、尺度、拍摄用途 | 功能家具与动作区域、路径、建筑层次、可指认锚点、有源光影 |
| 道具 | 造型辨识、物理结构、使用与剧情功能 | 轮廓、连接、握持／开合方式、材料、有效视图与所需状态 |
| 封面 | 手机缩略图吸引力、类型与情绪 | 主视觉、身份／视线／关系、标题与图像共同构图 |

“美式审美”结合目标市场、题材、人物生活环境与用途，不固定为某种脸型、肤色、衣服或配色。正式提示词用可见设计语言，品牌、作品与工作室名不能替代构思。

## 有条件的检查与反馈

无成图时只做设计预判和提示词审阅。实际看图后按用途选择检查：封面优先缩到目标列表尺寸看焦点、身份与标题；场景看动作空间，服装看搭配与自然动作，道具看结构与可读信息。

遮字只在需要单独诊断主图时使用，标题本身可参与主焦点；灰度检查只诊断明度层级，依赖色彩区分的有效方案不因去色失效而淘汰；模糊、删除元素等检查也仅帮助定位问题，不作为统一否决。无用元素可减，有功能、归属、情绪或整体平衡作用的元素可保留。

反馈区分 **设计选择、提示词表达、生成执行**。一次成败记录来源、任务条件和实际证据，不扩展为永远禁用某单品／构图，也不归因于单个词。未见新图不声称审美、点击率或生成一致性已验证。

## 按需参考

参考和案例只在有关问题上调用，优先查原图、原提示词、用户反馈及适用条件。已有资料难检索时才补轻量索引，不强制每次先看成功例。案例不足、环境陌生或连续失败时再定向联网，实际看图并记录来源与用途；不盲目增加图量。
