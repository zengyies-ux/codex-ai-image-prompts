# 海外 AI 短剧视觉资产提示词

本技能是**任务路由**，不是四模块详细规则的复制本。根目录 [`AGENTS.md`](../../../AGENTS.md) 与 [`工作台/共享基础.md`](../../../工作台/共享基础.md) 管理项目目标、来源优先级、共享事实账、版本、反馈、默认只写提示词和跨模块硬限制。详细规范由当前模块 reference 管理；`references/core-memory-v4.1.md` 仅是历史资料。

## 开始

1. 明确当前剧目、本轮模块和任务阶段：解读／资产表核验／提示词／成图反馈／实际出图。
2. 只读当前剧本、该剧 `剧目状态.md` 和本轮输入；完整剧本只建立一次共享事实账，四模块复用。不要遍历所有历史剧目。
3. 按下表进入一个模块，不加载其他模块全部规则。混合任务可按请求同时进入多个模块，但每项资产仍用所属模块的编号、画幅与质检。
4. 默认写实仿真人。只有用户明确要求动画，或当前剧目已有确认的动画风格，才读取 [`风格项目/明亮写实卡通/风格规范.md`](../../../风格项目/明亮写实卡通/风格规范.md) 的相关章节；风格只覆盖视觉语言与动物尺度，不改事实、取舍、编号和状态规则。

## 跨模块交付判断

- 有用户资产表先核验且保留来源映射；无表时从剧本建最小完整清单。用户决定实际制作范围，不静默删除、合并或改名。
- 信息不足时先完成不依赖缺口的部分，只在缺口实质影响当前交付时提问。
- 默认只交付可复制的图片提示词；用户明确要求实际生成图片才调用出图。
- 区分 `提示词已完成`、`图片已生成`、`用户已认可`。实际成图反馈先观察图，修订对应提示词，再更新当前剧状态。
- 同一份已确认角色、道具、场景的设计可以跨模块调用；场景空镜、角色空手、道具白底与封面文字规则不可跨模块套用。

## 场景状态帧的关键边界

`<基础空间ID>-Snn` 是对应基础空间的**状态编辑**。基础成图尚未获认可时只登记需求；用户确认基础图满意后可预写引用该图的编辑提示词，不必为了写文字再次上传。实际执行图片编辑时，必须上传已认可的基础图作为唯一视觉参考，并锁定机位、透视、裁切、结构、门窗、固定家具、材质、颜色和位置，只改允许的状态变量。新机位、新结构或移动固定家具不能冒充 Snn。详细取舍与质检以场景 reference 为准。
