# 海外 AI 短剧视觉资产提示词

以图片设计与提示词为核心。本技能只路由任务；[AGENTS](../../../AGENTS.md) 与 [共享基础](../../../工作台/共享基础.md) 维护共同输入、事实、反馈与硬限制。详细规格由当前模块维护，历史 `core-memory-v4.1.md` 不进入默认阅读链。

## 开始

1. 明确本轮模块、用途和必要条件。文字需求、独立试装、单张设计或局部修改可直接工作，无需先提交完整剧本、建剧目目录或资产表。
2. 用到参考图先实际打开，确认职责和还原／转译／改版目标。构思时按 [共用设计方法](references/visual-design-foundation.md) 观察具体关系与取舍；局部修复、忠实还原和已选方案无需完整探索。
3. 用户指定剧目或要求剧情一致时，从 [剧目入口](../../../剧目/README.md) 找到本剧，核实版本、状态、有关事实及原文。首次完整剧本制作任务通读并建立解读；复用旧解读时核实覆盖范围，不宣称读过未读取全文。未指定剧目不要猜测或遍历历史资料。
4. 进入下表当前模块。混合任务可读取相关多个模块，但编号、画幅和检查各自使用。默认写实仿真人；明确要求或本剧已确认动画时，按需读 [风格规范](../../../风格项目/明亮写实卡通/风格规范.md) 的相关章节。

| 模块 | 入口与按任务读取的规范 | 模板 |

| 场景 | [场景入口](../../../工作台/模块/场景.md)；拆整剧资产用 [workflow](references/scene-workflow.md)，写图用 [prompt standard](references/scene-prompt-standard.md)，交付用 [QA](references/scene-qa-checklist.md) | [场景模板](../../../模板/新剧目/02_场景提示词模板.md) |

## 交付边界

- 缺资料仅在会实质改变当前结果时提问；低影响选择标注假设后完成。充分输入、已选方向或明确修改目标直接交付，不重复审批，不增加用户要求的数量。
- 整剧资产任务有表先核验并保留来源映射；无表从已通读剧本建最小完整清单，由用户确认范围再分批制作。不静默删除、合并或改名。
- 默认只写可复制提示词；明确要求才实际出图。分别记录 `提示词已完成`、`图片已生成`、`用户已认可`。
- 反馈先看图，区分设计选择、文字表达、生成执行；单剧事实留本剧，稳定经验才进入项目记忆。身份参考不自动决定造型；空镜、空手、白底不跨模块套用。

## 场景状态帧边界

`<基础空间ID>-Snn` 是获认可基础空间的状态编辑。基础图未获认可仅登记需求；认可后可预写引用该图的编辑文字。实际编辑必须以对应已认可基础图为唯一图像参考，锁定机位、透视、裁切、结构、门窗、固定家具、材质、颜色和位置，仅改允许状态。新机位或结构不是 Snn，详见场景规范。
