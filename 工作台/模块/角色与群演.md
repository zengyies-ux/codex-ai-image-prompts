# 角色、服装与群演模块入口

适用于独立人物与服装设计、参考转译、小范围改词，以及指定剧目的角色资产、服装板与群演组图。先读 [共享基础](../共享基础.md) 的输入路由与共同限制；仅在任务指定剧目时进入该剧资料。不要把场景空镜或道具 4:3 白底规格套在角色上。

## 按输入直接开始

| 当前输入 | 必要条件与路径 |
| --- | --- |
| 文字需求、单套试装或局部修改 | 确定成年／适龄对象、用途、场合、所要数量与形式；输入足够就设计并写提示词，不要求全剧、剧目目录或资产表。低影响信息标明最小假设。 |
| 服装参考图 | 确定忠实反推、关系转译或改版职责，实际打开图片，简记具体比例／材料／层次、配合关系及本次保留与调整；身份图只锁身份。 |
| 指定角色或整剧资产 | 核验相关身份、场合、剧情阶段与已确认造型。首次完整剧本资产任务按共享基础通读并建立可复用解读；后续核实版本、覆盖与相关原文。有资产表保留来源映射，用户决定制作范围。 |

女主、男主、男二、女二的**正式核心控脸服装板**仍需用户提供或确认的身份脸图；缺图时不能冒充已锁定身份。自洽的独立设计简报可直接交付英文试装候选，标明“独立候选，未锁定正式角色”，不强制退回中文概念或索取完整剧本。用户只要一套就只交付一套。

命名且需跨镜头辨认的配角可按已核验设定自主定脸并做独立角色板；第一张获认可后锁定身份。无持续身份需求的功能人物可组合为群演组。缺失信息只有会实质改变当前交付时才提问。

## 按需读取与交付

1. [角色板与群演标准](../../.agents/skills/drama-image-prompts/references/character-standard.md) 维护身份、编号 `Cnn-Lnn`／`Gnn`、版式、体型、允许饰件与质检。
2. 具体服装读 [设计系统](../../.agents/skills/drama-image-prompts/references/wardrobe/design-system.md)：从需求与整体关系设计、比较取舍并写提示词。没有参考也能自主设计；局部修复、忠实反推和已确认方案可直接处理。城市、气候、阶层与市场有实际影响时才读 [本地化系统](../../.agents/skills/drama-image-prompts/references/wardrobe/market-localization.md)；缺构思语言时查 [设计关系词库](../../.agents/skills/drama-image-prompts/references/wardrobe/style-library.md)；研究缺口或连续失败时查 [研究记录](../../.agents/skills/drama-image-prompts/references/wardrobe/research-notes.md) 与相关案例。都不强制每套读取。
3. 按当前形式选用 [角色提示词模板](../../模板/新剧目/04_角色提示词模板.md)，独立任务无需建立剧目或编正式资产号。指定剧目的反馈与状态回写该剧；独立测试单独保留。
4. 用户选择拟人动物动画时才读 [可选风格规范](../../风格项目/明亮写实卡通/风格规范.md) 的角色章节，不继承真人九头身数字。

正式角色服装板默认 16:9、左高清面部、右正面／单侧严格 90°／背面全身；审美试装为 9:16 正面完整全身。两者均全白背景、双脚站稳、空手自然垂于大腿两侧。群演另按群演组图规格。女装胸部覆盖、身份连续性等制作约束保留，设计方法不设固定候选数或额外审批。

默认只写提示词；用户明确要求时才出图。成图前只能记录设计预判，提示词完成、图片生成、用户认可分别记录。
