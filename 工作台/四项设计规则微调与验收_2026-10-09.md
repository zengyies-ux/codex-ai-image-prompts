## 修改范围

| 问题 | 本次处理 | 维护来源 |
| --- | --- | --- |
| “需要时探索”缺少触发条件 | 开放设计收到强设计、新颖、抓眼要求或连续普通反馈时，先内部比较实质不同的方向；忠实反推、已选方案和局部修复不重做有效主体，不增加套数或审批 | [共用设计方法](../.agents/skills/drama-image-prompts/references/visual-design-foundation.md)、四模块相关标准 |
| 整套设计禁令可能妨碍用户反推参考 | 用户提供图片并要求反推时，可保留整套可见关系；用户指定调整与标识、覆盖等硬限制继续落实。独立原创任务不机械照搬历史案例 | 共用设计方法、[服装设计系统](../.agents/skills/drama-image-prompts/references/wardrobe/design-system.md) |
| 通用体型偏向女装的轻窄骨架 | 纵向比例与肩胸、腰胯体量分别确定；已确认的宽肩、饱满胸背男主保留力量感，其他已指定体型同样优先；服装腰线按款式确定 | [角色标准](../.agents/skills/drama-image-prompts/references/character-standard.md)、角色模板、项目记忆相关条目 |
| 灵感资料采用统一生活优先排序 | 按研究目的取资料：生活资料核验穿着，秀场／裁剪／工艺资料拓展强设计，再转译到当前场合和覆盖要求 | [本地化系统第二节](../.agents/skills/drama-image-prompts/references/wardrobe/market-localization.md) |

正式四模块、三类输入路由、默认只写提示词与现有资产规格继续沿用。没有新增目录层级、资产管理流程或额外必填表。旧剧本、解读、成图和历史案例未改写；旧验收中的男装小样属于当时的测试记录，其轻窄体型措辞不作为现行男性默认值。

## 边界走查

以下为修改者对任务边界的人工规则走查，不是另一个新聊天的执行测试，也不是出图验证。

| 测试需求 | 修改后的处理 |
| --- | --- |
| “重新设计，只要一套，要新颖抓眼” | 内部比较有结构差异的方向，交付仍只有一套；不让用户先审批候选 |
| “这套很好，只把领口提高” | 保留轮廓、搭配与已认可项，处理领口、内衬及必要固定结构；不因原目标是大胆而重新探索 |
| “照我上传的整套服装反推，去标识、不露沟” | 实际看图后保留可见轮廓、比例、层次与色材，注明标识和覆盖调整；不擅自换成普通通勤装 |
| “修长但宽肩、饱满胸背的成年男主” | 修长比例与有力量的肩胸并存，不沿用女装的纤窄胸廓 |
| “清瘦男配／丰满女角，已有身体参考” | 遵从已指定体型，不强制肌肉化、纤细化或改变参考比例 |
| “高定晚宴创意不足”与“核验雨天通勤衣物” | 前者重点看秀场、工艺和廓形，再处理行动及覆盖；后者先核验天气、职业和出行条件；资料充分时均不强制继续搜索 |
