## 已修复的冲突和重复

- 根入口原先包含整段服装、道具、封面和场景操作细节；现收敛为路由与共同底线，详细规则留在对应 reference，场景任务无需加载服装全套。
- `scene-workflow.md`、场景提示词模板旧句要求“先上传基础图才可写 Snn”。现统一为：**基础成图获用户认可后可预写编辑提示词；实际执行编辑时才须上传该基础图作为唯一视觉参考**。质检项也分别检查文字预写和图片编辑。
- 默认写实仿真人与可选动画覆盖层在总入口、模块入口、独立指南和本地包保持一致；动画章节不自动进入普通写实任务。
- 旧场景工作流中的具体人名示例已换为显式占位符；`项目记忆.md` 尾部单剧“当前剧目”改成历史入口说明；动画 README 不再声明过时的“首次角色成图仍待验证”。
- 场景模板把模型、尺寸、质量档位改为平台可调参数；每条基础提示词第一句自带固定 16:9，独立复制仍能使用。
