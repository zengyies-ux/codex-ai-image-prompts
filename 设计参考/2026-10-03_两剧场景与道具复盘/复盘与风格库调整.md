# 两剧动物场景与道具复盘

日期：2026-10-03。用户要求简单复盘两本动物城场景、道具制作与风格库，为后续动物配角作准备。本轮以既有剧本事实账、确认状态、反馈原图及提示词版本复核；不重建剧情、不新增资产或出图。

## 学到了什么

| 经验 | 具体落实 | 来源与证据边界 |
| --- | --- | --- |
| 场景要按动作与功能拆分 | 大地点下面核对门口、主要动作区、必要功能区、回忆／短插入；旁白画面化按用户范围保留来源。按功能补齐，不按集数凑数量 | 《楚门》原22项扩为56功能空间＋8过渡；扩展由用户授权，不证明每项都必须独立出图 |
| 卡通感由可见造型建立 | 主轮廓、厚薄、曲直、比例及色块写具体；纹理、反射和磨损服从动画设计 | 《楚门》首轮被指出写实，v02方向被文字认可；未收到三张测试图逐图观察 |
| 风格与装修等级分开 | 龙剧同一媒介下，权贵庄园有成套建筑及家具工艺；普通住房、医院、机场分别按功能设计 | C旧五图有实际观察证据，窄金线和灰棕没有兑现贵气；升级后用户报告改善，未提供新图 |
| 减法要控制视觉竞争 | 动作物分开可指认；保留场所容量、家具、织物、陈列和成组生活痕迹，构图和有源光影组织主次 | 用户四图对比认可分色与减法，后续又要求细节恢复中间值；视频识别效果尚未实测 |
| 动物生活感来自使用逻辑 | 爪握、尾巴留空、可达高度加局部生活点缀；萝卜等要与本剧使用者及地点有关系 | 都市v02局部萝卜得到文字认可；具体身高、物种与配角脸不能由此反推 |
| 同一大场景延展需要持续设计 | 重复明确门窗、色材、灯具和主要家具关系；每个小场景另有自身动作重点 | 龙剧C及都市后批用户反馈暴露装修力度与设计权重丢失，不靠堆同义风格词补救 |
| 道具先表达叙事身份 | 轮廓与工艺表达私人纪念、职业荣誉或日常用品；能拿、放、擦、操作，多视图同结构 | P08 v01实际图被用户指出low；空框、低圆牌、矮底座偏桌面摆件。v02光圈雕塑仅文本候选，尚未验证 |
| 道具连续性包括归属与状态 | 同一伤痕、接口、铭文、壳色与贴纸在各视图一致；手机UI独立，流转不换实物身份 | P01四条及四款手机为已交付设计文本；未把提示词一致等同成图或视频一致 |
