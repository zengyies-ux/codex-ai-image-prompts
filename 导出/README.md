# 图片提示词工作台｜独立发布物

本目录发布场景与封面模块的独立文件包。组员可把其中一个模块交给另一位 AI 使用；本地主项目仍保留场景、角色与群演、道具、封面四个模块。两个包均支持文字需求、实际查看参考、指定剧目三种输入；充分的独立设计资料可直接工作，不要求先制作其他模块资产。封面保留准确完整英文剧名及必要身份／关系。

## 场景包｜2026-10-08 / v1.6

| 发布物 | 适合使用方式 |
| --- | --- |
| [单份 Markdown](场景图提示词工作台_独立指南.md) | 直接上传普通 AI 聊天；再给本轮需求或参考；指定剧目补相关事实，整剧任务提供完整剧本和已有表（如有） |
| [本地目录](场景图提示词工作台_本地包/README.md) | Codex 或其他能读取文件夹的工具，从包内普通 `README.md` 开始 |
| `场景图提示词工作台_本地包.zip` | 复制或分享本地目录；解压后仍从包内 `README.md` 开始 |

场景 v1.6 支持独立文字、参考转译和指定剧目设计；剧本按需核验，首次整剧仍通读。观察具体视觉关系后构思取舍，局部修复／已选方案直达；固定焦段与细节配额不作门槛。保留原规格、来源映射和 Snn 前提，未生成新图片。

场景 v1.5 同步两条用户偏好：额外过渡／时间流逝空镜仅在用户主动要求后制作，不自动在资产表末行增加空镜组，既有已授权空镜保留；同宅不同功能空间默认独立构图，仅统一装修等级、语言和色材，剧本或用户要求跨房间视线／关键动作时才设计所需连接，必要剧情入口保留。单份指南、本地规则、质检、使用说明与 ZIP 已同步。

场景 v1.4 补入现实国家国旗、国徽及可识别官方国家徽记排除，保留剧情核验的原创虚构标识，不泛化禁用所有旗帜；规则、模板、质检与 ZIP 已同步。

第一次使用先看 [小白使用说明](场景图提示词包_小白使用说明.md)：包括打开方式、A01／A02／B01／Snn 编号、出图顺序和可直接复制的第一句话。本地包内也提供相同的 `快速上手.md`。

场景 v1.3 将细节密度调整到中间值：功能家具、建筑层次和成组生活内容保留，动作参照物分色及通路继续清楚。单份指南、本地规则和质检已同步，ZIP按最新目录重建；未声称新图或视频实测通过。

场景 v1.2 同步了实际可见回忆／短插入覆盖、可指认且跨图稳定的动作参照物、物体减法与核心功能物构图、光影层级，以及克制的动画亲和感；单份指南、本地规则和模板已同步，ZIP 按最新目录重新打包。图片只是设计反馈，未记录为后续视频效果实测。

场景 v1.1 复核修复了模板复制到任意剧目目录后的外部相对链接，以及 Snn 模板中固定位置与允许变化之间的措辞歧义；ZIP 已按最新目录重新打包。场景小白说明的维护来源是主项目 `工作台/场景模块_小白使用说明.md`。

## 维护来源与同步

主项目中的 [共享基础](../工作台/共享基础.md)、[场景模块入口](../工作台/模块/场景.md)、场景 `references/scene-workflow.md`／`scene-prompt-standard.md`／`scene-qa-checklist.md`、[封面模块入口](../工作台/模块/封面.md)、封面 `references/cover-standard.md`／`visual-design-foundation.md`／`cover-inspiration-and-cases.md`、对应新剧目模板，以及按需启用的 [动画风格规范](../风格项目/明亮写实卡通/风格规范.md)，是长期维护来源。本目录的单份 Markdown、本地目录和 ZIP 是按日期发布的快照；包内必读规则与链接应能脱离主项目独立使用。

更新原则：先修改主项目维护来源 → 对照修改该模块的单份 Markdown 与本地包 → 重建该模块 ZIP → 解压验证包内文件与相对链接。场景复核资产取舍、Snn 前提、16:9 空镜、材质色值、反馈三状态和可选动画分支；封面复核剧情事实、身份参考、3:4、标题准确性、服装与光照、创意自由度、反馈三状态和按需联网方法。发现导出物错误时，也将修正回写主项目，避免发布快照与维护来源分叉。

封面小白使用说明的维护来源为[主项目说明](../工作台/封面模块_小白使用说明.md)；对外单页和包内 `快速上手.md` 是同内容副本，更新时同步。模板复制约定来自主项目 README；复制后的模板也需在独立剧目目录检查内部链接。

发布包不包含剧本、资产图、角色脸模或历史成图。独立设计只提供该任务必要的需求和参考；指定剧目提供有关事实与版本，整剧任务首次提供完整剧本。封面正式交付保留准确英文剧名与必要身份信息。

本轮入口、规则、小样与发布验证见 [重构合并验收](../工作台/重构修改与验收_2026-10-08.md)，不属于使用包的必读前置。
