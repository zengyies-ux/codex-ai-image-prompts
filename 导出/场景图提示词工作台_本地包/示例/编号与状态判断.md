# 虚构示例｜编号、功能延展与状态

**以下公司与人物均为说明规则的虚构例子，不属于任何真实剧目，也不是待制作资产。**

假设剧本明确出现一家公司的开放工位、老板办公室；同一办公室又在夜间停电时发生关键行动。人物只在台词中提到另一个城市的仓库。可以这样判断：

| 需求 | 处理 | 原因 |
| --- | --- | --- |
| 开放工位区有剧情行动 | `A01` 母版 | 它是核心、可复用且实际有用途的空间 |
| 人物进入老板办公室谈判 | `A02` 功能延展 | 与工位同楼却承担不同功能；现有工位图不能呈现室内办公桌和私密门口 |
| 在工位反向拍摄一次 | 通常复用 A01 | 单纯改变观察方向不足以新增资产 |
| 老板办公室夜间停电，剧情必须看出停电 | 先登记 `A02-S01`；基础图获认可后预写状态编辑提示词，实际编辑才上传该图 | 同一空间的必要状态；不能把 Snn 作为独立文生图 |
| 想移动老板固定办公桌，改拍窗边 | 非 Snn；再判断是否有必要独立底板 | 固定家具和机位改变违反状态锁定，但并不自动证明需新资产 |
| 仓库仅被口头提及 | 默认不建图 | MENTION 没有视觉生产需求；用户明确指定例外 |

视觉连续性只要求 A01 与 A02 共享已确认的建筑等级、材质与局部锚点，不要求两张图能像建筑图纸一样拼接。场景提示词仍默认 16:9 空镜，具体颜色和灯光必须从**实际剧本与用户要求**重新决定，不能从示例推导。
