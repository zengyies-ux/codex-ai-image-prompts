# 可选风格分支｜明亮写实卡通场景

**仅在用户明确选择**“写实卡通”“明亮三维动画”“拟人动物动画”等方向，或当前剧目状态已确认该风格时启用。普通任务继续使用[默认写实规范](../场景规则/02_画面设计与提示词.md)，无需读取本文件。此分支不是第五个资产模块，只替换视觉措辞与世界尺度；剧本事实、资产取舍、编号、Snn、16:9 空镜、用户范围决定权和交付状态仍按主规则。

## 视觉目标与设计顺序

目标是**原创、高品质三维动画环境**：从缩略图就能看出经过设计的大形、建筑剪影、比例和色块；再由可信的体积、接触、材质与光线支撑世界。不要用写实房产效果图加几个圆角代替动画。写提示词顺序为：`原创建筑形状 → 色块节奏 → 动画材质 → 有来源的光影 → 少量真实细节`。

“明亮”是可用时的基础气质，不是所有戏都强制高曝光。夜景、悲剧情节、黑暗势力或密闭空间可以更冷、更沉，但建筑功能仍清楚、色彩有层次、焦点可读；压力可由尺度、门廊、光路和空间秩序表现，不要简单把所有颜色压成灰黑。一个剧目内的饱和度与明度应服从用户已确认的视觉方向。

2026-10-01 用户进一步要求场景的卡通亲和感**克制地增加一点**：从略柔和的轮廓、适度夸张的门窗与家具比例、少量有节奏的不对称、协调饱和色面和柔化材质入手，保留承重、通行与使用逻辑。庄严或压迫空间仍按剧情保持结构秩序；不把所有家具做圆胖、满屋加动物符号或改成幼儿游乐园。该调整只针对本分支场景，不改角色外貌。

场景优先服务后续表演：必要参照物有稳定的颜色／轮廓／空间位置，重复家具减少并分开，核心功能物与动作区在画面中清楚可读。灯光与构图加强层次，不能用更多摆设、更多灯具或全局提亮代替。具体执行见[画面设计与提示词](../场景规则/02_画面设计与提示词.md)，不给所有空间套同一物件数量或彩色座位配方。

2026-10-02 用户将场景细节调整到中间值：动作参照物分色与稳定位置继续保留，功能家具、织物、陈列和成组生活信息恢复到次级区域；建筑层次与有源光影增添美感，动作区和通路保持清楚。数量按功能与容量确定，不设统一硬上限。

## 同剧原创世界卡

多场景剧目需要连续性时按相关资料记录；独立单张按本轮用途选择条件，无需完整剧本或强制世界卡。不跨剧直接复制：

| 项 | 要决定的内容 |
| --- | --- |
| 地点与生活 | 国家／城市、季节气候、阶层、交通与机构生活，由剧本或标明的假设给出 |
| 物种与尺度 | 剧本有哪些物种；若多体型角色共同生活，门把手、台阶、座椅、通道、柜台如何可用 |
| 建筑形状 | 两三种原创的门框、屋檐、立面或遮阳构件关系；有承重与通行逻辑 |
| 色材 | 主色、辅色、强调色及各自绑定的材料；按地点等级改变面积，不让全部地点同色 |
| 灯光 | 太阳、天空、窗户或实景灯具来源；阴影色和反弹色有方向和空间依据 |
| 标识 | 不出现现实国家国旗、国徽及可识别官方国家徽记。 只用有画面用途、准确核准的原创文字或图标；绑定剧情时核验有关原文，不用第三方品牌或参照作品标识 |

同一大场景的延展重述世界卡中与本图可见的关键锚点，不依赖“沿用之前”几个字。仍不要求各图能精确拼成完整三维户型。

## 五个可见控制点

1. **形状**：先设计建筑体块节奏与清楚外轮廓。门、窗、阳台、扶手可适度拉长或放大，但尺寸仍支持动物角色行动；避免把一切做成圆胖玩具。严肃建筑可用坚实层级、压低入口、深窗洞与控制轴线呈现权力。
2. **材料**：石、木、陶、金属和玻璃用宽的哑光面、软化高光与少量近景纹理区分。真实磨损只辅助，不让密集石纹、镜面反射和微细节压掉动画形状。
3. **色彩**：用较明确的冷暖、大色面与饱和度层级引导入口、动线、操作区。蓝紫或青绿阴影可美术化，但仍服从光源，不能靠统一滤镜代替材质。
4. **光影**：软化、概括，但太阳／天光／窗灯来源明确；阴影与色彩反弹能解释空间体积、接触与方向。少用楼盘广告式过曝大理石和无源镜面亮斑。
5. **镜头和用途**：描述机位、前中后景、核心动作区与剧情物件可读尺度。具体毫米焦段只在确有构图作用时写；避免整个提示词变成摄影设备说明。

动画分支**每条场景英文正文第一句**明确 `A fixed 16:9 landscape frame...`。随后写清原创三维动画媒介、大形、空间功能、相机与动线、物种尺度、色材、光源、4—8 个材质绑定 Hex 色值、必要限制。场景仍是空镜：不出现人、拟人动物、背景人群、剪影或人／动物形反射。正式提示词不得写受保护作品、工作室、现有角色或其标志性城市元素，也不要要求复制参考画面。参考只能提炼抽象设计机制。
