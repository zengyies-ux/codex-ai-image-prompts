# 新剧目模板｜只复制当前需要的文件

独立单张需求、参考转译或局部修改可直接在对话交付，不必复制目录、填事实账或资产表。只有绑定剧目／批量资产需要持续记录时，新剧目可复制本目录至自己的工作目录，保留原始输入并填写场景相关文件。文件名可适配现有剧目结构；若用户已有资产表，优先沿用其名称、顺序、图片列和来源编号，内部核验另记。不要把模板中的占位符或工作台示例当作剧本事实。

AI 先通过工作台根目录的 README 读取相关规则，再复制并填写本模板。模板中的链接仅指向一同复制的剧目文件，不以 `../../` 等相对层级访问工作台规则，因此剧目可以放在用户指定的其他目录。若修改剧目文件名，顺手更新同目录中指向它的链接。

```text
〔剧名〕/
├── 00_输入/                  原始剧本、用户资产表、参考图片；不覆盖
├── 01_共享事实账.md         首次整剧任务通读后建立一份；已有解读按需核验
├── 02_场景核验记录.md       内部证据、来源映射、取舍与假设
├── 03_场景资产表.md         面向制作团队的极简名称／图片表
├── 04_场景提示词.md         基础空间的中文标题＋完整英文正文
├── 05_状态帧需求与提示词.md 基础图确认前登记需求，确认后可预写
├── 06_反馈记录.md           实际成图和文字反馈
├── 07_剧目状态.md           当前有效版本、风格、制作三态
└── 99_归档/                仅在有被替换的旧版时建立
```

团队若使用电子表格，可把 `03_场景资产表.md` 的同一横向结构建为 `.xlsx`，但不要把内部证据、审批列或状态列塞进去。已有电子表格时不必转换。其他模块可以复用 `01_共享事实账.md`，但角色、道具、封面有自己的格式和规则，不使用场景空镜或 Snn 模板。

首次整剧资产任务填表顺序：先把原始剧本放入 `00_输入` → 通读并填写一次事实账；已有解读核验版本、覆盖范围与相关原文 → 核验或建立资产清单 → 由用户决定制作范围 → 一次写完当前大场景家族 → 用户出图反馈 → 更新三态。`05` 只有真的存在必要状态图时才填写。默认只交付文字提示词。
