# 场景规则 04｜交付质检与成图反馈

每轮先确认正在交付的是**资产表、提示词、实际图片、还是对成图的修订**。没有图片就只能做文本审查，不能写“效果已验证”。

## 1. 交付前检查

### 剧本、事实和范围

- 已通读整部剧本；实际发生 `ACT`、视觉插入 `VIS`、仅提及 `MENTION`、状态变化 `STATE` 分得清楚。
- 实际可见回忆、梦境、短插入和一小段剧情中的空间，是否逐项映射到已有资产、补充项或待核实项，没有因为短暂而漏掉？是否把口述回忆误当成可见回忆，或反过来？
- 城市、年代、时间、天气、人物生活层级、动作与情绪有证据；美术假设单独标记。没有混进其他剧目的人名、地点、机构或色板。
- 有用户资产表时保留其名称、顺序和来源映射；任何合并或删减先说明，不静默改表。用户指定的制作范围已覆盖。
- `A01` 有实际剧情用途；每个延展带来必要功能空间或关键结构；没有为普通反打、另一机位或展示美术制造资产。不能把同栋楼里的工位与老板办公室误合并。
- 额外过渡／时间流逝空镜是否来自用户主动要求，而非自动补在末行？是否区分额外过渡空镜与正常无人剧情场景底图，且没有追溯删除此前已授权的空镜资产？

### 编号、连续性与状态

- 大场景从 A/B/C 各自 `01` 开始；同一地址体系内延展沿用字母，独立地点开新字母。
- 延展独立复述必要的空间结构、材质、色板和锚点；没有用“同上”代替完整提示词。
- 同宅不同功能空间是否默认独立取景，仅统一装修等级、语言和色材？跨房间可见性、门洞连接或贯通透视是否确有剧本／用户要求，未为户型展示而强行加入？必要剧情入口是否仍保留？
- Snn 只在用户**已认可对应基础成图**后预写；预写可不再次上传图。执行图片编辑时，图已作为唯一参考上传。锁定项与允许变化项写清；新机位或移动固定家具不冒充 Snn。

### 画面与英文正文

- 标题中文；每一基础场景只对应一段可独立复制的英文提示词。第一句明确固定 16:9 横图，媒介与地点清楚。
- 前中后景、相机位置、视觉锚点、动作区、出口动线和空间用途可读；固定家具无多余或相互矛盾布局。
- 能否根据画面单独指认角色要坐的座位、进入的门、站立或操作的位置？必要同类参照物是否有准确数量、清楚间隔以及颜色／轮廓／位置区别？
- 核心功能物及其动作区是否足够清楚？是否出现“舞台和屏幕很大，实际讲台仍很小”等失焦？
- 重复家具、前景遮挡及装饰是否抢占动作区？删减后是否仍保留剧情必需物件、通行路径和场所的可信规模？
- 是否保留足够的功能家具、建筑层次及成组生活／工作细节，让地点漂亮且可信？是否因过度减法空成样板间，或添加细节后重新遮挡动作物和路径？必要分色参照物是否继续清楚？
- 同一空间的参照物本色、造型和位置关系是否延续，没有因光照或机位变化重新分配？
- 材质与尺度可信；一至三个叙事细节服务剧情；4—8 个 Hex 与具体材质绑定。
- 主辅光、方向、落点、衰减、色温、阴影和反射合理；体积光有可解释的光源。
- 默认空镜，无人、剪影、背景人群或人形反射；动画分支还要排除可见拟人动物与动物形反射。
- 无宗教元素；无现实国家国旗、国徽及可识别官方国家徽记；相关车辆、电子设备、包装、酒瓶、设施和标识无可识别第三方品牌。剧情确需虚构文字时，拼写已确认并跨资产统一。
- 正文不用参照作品、工作室或现有角色名作为风格捷径；不加长串无关负面词，也不宣称某模型会严格遵守未经验证的参数。

## 2. 实际成图反馈

用户上传成图时，先观察图片本身，再将问题归入：`场景功能不可读／结构布局／机位与画幅／风格媒介／角色或反射混入／关键道具尺度／光影／色彩材质／文字品牌／状态连续性`。指出图片里看见的证据，并判断是提示词缺失、描述冲突、模型执行偏差，还是用户要求改变。只改相关句子与必要相邻部分，避免因为一个局部问题把全剧色板推翻。

成图反馈**默认用于改原生文生图提示词**。除非用户明确要求图片编辑、上传某图作视觉参考，或正在执行 Snn，不把已看到的图片自动变成下一轮生成输入。

记录三个独立状态：

| 状态 | 判定条件 |
| --- | --- |
| 提示词已完成／已修订 | 文本已经交付并标明版本 |
| 图片已生成／已观察 | 实际有对应图片；若未看图，不写“已观察” |
| 用户已认可 | 用户明确认可该图片或方向；区分认可文字定调与认可实际成图 |

反馈写入该剧的[反馈模板](../模板/新剧目/06_反馈记录.md)及[剧目状态](../模板/新剧目/07_剧目状态.md)。一次局部图片问题只影响该资产；用户确认某种跨剧稳定偏好后，才回写维护源。

## 3. 最小零上下文走查

在交付本包或新剧提示词前，逐条以没有原聊天的新 AI 视角走查：默认无风格指示→写实；已有表→保留来源；公司工位与老板办公室→必要时分开；新机位／移固定家具→非 Snn，继续判断资产价值；基础图已认可但未重新上传→可预写 Snn，不能实编；基础图未认可→只登记状态需求；明确动画→读取可选分支并仍空镜；只要提示词→不出图。若包被复制到其他目录，所有必需链接仍应指向包内文件。
