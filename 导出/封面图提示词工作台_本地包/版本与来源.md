# 版本与维护来源

封面本地包：**2026-10-02 / v1.1**。它与同级发布物 `封面图提示词工作台_独立指南.md` 属于同一版的两种交付形式：普通聊天用单文件；可读取目录的工具从本包 `README.md` 开始。两者都不需要安装 Skill，也不以原项目中的路径作为运行依赖。

长期维护来源在原四模块项目：`工作台/共享基础.md`、`工作台/模块/封面.md`、`.agents/skills/drama-image-prompts/references/cover-standard.md`、`visual-design-foundation.md`、`cover-inspiration-and-cases.md`、`模板/新剧目/07_封面方案与提示词模板.md`、`工作台/封面模块_小白使用说明.md`。本包是供组员分发的**发布快照**，不要在源文件、单文件、包内文件三处各自发明新规则。

维护顺序：先修主项目封面维护来源 → 对照同步单文件和包内相关页 → 更新小白说明两个副本 → 检查链接与硬限制 → 重建 ZIP → 解压比对。共用视觉框架若需修改，先检查它对场景、角色、道具的影响；封面专属变化优先留在封面规则。

案例只用来说明**有条件的方法**，不是任一剧的固定构图、人物或配色。官方网页画面是 2026-09-29 的目视抽样，不证明点击率；本地失忆题材三图的成图观察与用户约 78 分的评价分开记录；机车题材在包内仅有用户文字／历史复盘，不冒称本轮看过成图。没有后续成图证据的提示词设想标为未验证。


v1.1（2026-10-02）仅同步共同硬限制：排除现实国家国旗、国徽及可识别官方国家徽记，保留剧情核验的原创虚构标识；其余封面流程与设计细则不变。
