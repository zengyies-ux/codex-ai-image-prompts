# 封面图提示词工作台｜本地包入口

发布版：**2026-10-09 / v1.3**。本目录可整体移出原项目，作为普通 Markdown 文件包交给另一个 AI；不需要安装 Skill，也不需要先做其他模块资产、建剧目目录或填资产表。本包只负责海外短剧剧集主封。

## AI 请按这个顺序使用

1. 先读 [封面规则与流程](封面规则与流程.md)，其中独立包含输入路由、设计方法、封面规格、标题、参考与反馈规则。
2. 充分独立简报、图片参考或已选方案可直接设计；保留准确完整英文剧名、必要人物身份／关系和情绪信息。使用参考先实际看图。绑定指定剧目才核验其版本与相关原文；首次完整剧本制作仍通读全剧。
3. 探索按需要比较不同整体方向，不固定数量；已选方案、局部修复、还原或只要一条时直接交付。要锁定已有角色身份时补齐必要脸图，明确授权原创人物时可设计候选。用 [交付模板](模板/概念与提示词.md) 参考格式，删除不适用栏位。
4. 灵感不足时可按需读 [灵感与案例](案例/灵感与证据边界.md)，带具体问题查官方视觉资料；不是每次必读、必联网。用户禁止联网时不搜索。
5. 用户回传成图，先实际看图，再按规则保留有效处并迭代。默认新写文生图提示词；明确要求原图编辑时才写编辑提示词。

给组员的上手话术见 [快速上手](快速上手.md)。[版本与来源](版本与来源.md) 说明维护位置、同步方式与证据范围。

## 默认与底线

默认写实仿真人、3:4、只交付提示词；用户明确要求出图才生成。完整准确英文剧名之外无其他文字。女性在要求的视角和自然动作下无乳沟、侧胸或胸部透视；必要身份与剧情事实不漂移；无宗教元素、现实国家官方标识和可识别第三方品牌。封面不继承空镜、空手、白底资产板规格。可选动画分支已内嵌在规则末尾，仅在用户明确要求或指定剧目已确认时启用，不依赖主仓库路径。
