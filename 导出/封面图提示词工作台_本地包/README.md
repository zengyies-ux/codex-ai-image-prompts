# 封面图提示词工作台｜本地包入口

发布版：2026-10-02 / v1.1。本目录可整体移出原项目，作为**普通 Markdown 文件包**交给另一个 AI；不需要安装 Skill，也不需要先做场景、角色或道具模块。本地原项目仍有四个模块，本包只负责海外短剧剧集主封。

## AI 请按这个顺序使用

1. 先完整阅读 [封面规则与流程](封面规则与流程.md)。它独立包含事实提取、概念选择、服装／场景／道具、标题、灵感检索、英文提示词与反馈规则。
2. 读取用户本轮提供的**完整剧本**、准确英文剧名、角色脸图、已确认事实与要求。无脸图可先设计概念；身份锁定版的最终提示词需补齐入画角色参考。
3. 按默认流程给 2—3 个实质不同的中文概念；若用户已选方向或直接要提示词，就直达完整英文提示词。用 [交付模板](模板/概念与提示词.md) 作为格式参考，不照抄其占位文字。
4. 灵感不足时可按需读 [灵感与案例](案例/灵感与证据边界.md)，带具体问题查官方视觉资料；不是每次必读、必联网。用户禁止联网时不搜索。
5. 用户回传成图，先实际看图，再按规则保留有效处并迭代。默认新写文生图提示词；明确要求原图编辑时才写编辑提示词。

给组员的上手话术见 [快速上手](快速上手.md)。[版本与来源](版本与来源.md) 说明维护位置、同步方式与证据范围。

## 默认与底线

默认写实仿真人、3:4、只交付提示词；用户明确要求出图才生成。封面带**完整准确的英文剧名**，除剧名外无其他文字。女性服装在姿态、角度和面料变化下**不露乳沟**；身份、关系与关键剧情事实不漂移；不出现宗教元素及可识别的真实第三方品牌／LOGO。 不出现现实国家国旗、国徽及可识别官方国家徽记。人物、场景和标题必须属于同一画面。动画分支只在用户明确要求或当前剧目已确认动画风格时考虑，不作为默认必读内容。
